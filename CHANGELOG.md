# Changelog

## 1.0.3 — First public release

- Local PDF editing with direct text entry, object movement, typography controls and undo.
- Page organization, annotations, forms, offline OCR and document tools.
- Signature Studio with local vector compositions, rubrics and drawing reconstruction.
- Searchable commands, task-oriented controls and a local recent-document library.
- Pointer-responsive Home lighting and expressive motion with app-owned preferences.
- Public-release hardening: updated PDF parser, complete distribution notices and compiler path remapping.

See the release notes for installation details and current limitations.

- Fixed an inspector-opening layout shift that could move a text object during selection. Pointer transforms now follow physical pointer travel.
